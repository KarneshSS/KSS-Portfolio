# Karnesh S S Portfolio Website

A modern tech portfolio website for Karnesh S S, showcasing skills as a tech enthusiast, coder, artist, and singer.

## Deployment Instructions

### Option 1: Netlify (Recommended)
1. Go to [netlify.com](https://netlify.com)
2. Sign up for a free account
3. Drag and drop the entire project folder to the deployment area
4. Netlify will automatically deploy your site and provide a URL

### Option 2: GitHub Pages
1. Create a GitHub repository
2. Upload all files to the repository
3. Go to repository Settings > Pages
4. Select the main branch and /root folder
5. Save to deploy

### Option 3: Vercel
1. Go to [vercel.com](https://vercel.com)
2. Sign up for a free account
3. Import the project folder
4. Vercel will automatically deploy your site

## Local Development
To run locally:
1. Open index.html in a browser, or
2. Use a local server like Live Server extension in VS Code
